## [0.9.0] - 2026-10-28

First public release.

### Added

- Always-on-top, click-through overlay for live NHL scores with compact and expanded views.
- Hat-Trick Watch, shutout watch, career milestones and point streaks.
- Notifications per event and channel: overlay toast, Windows notification, sound and voice.
- Gaming profile that switches to compact, click-through mode while a game is the active window.
- Watched-country players ("Finns tonight") with manual nationality corrections.
- Morning recap and spoiler shield.
- Focus dashboard with strength strip, shots by period, shot map and play-by-play.
- Standings with the playoff race and bracket.
- Optional Finnish Liiga section.
- Portable mode and settings export/import.
